Раздел 4

Методология и ограничения

Ключевые оговорки, которые необходимо учитывать при интерпретации результатов. Спутниковые данные — инструмент приоритизации полевых кампаний, не замена QP/CP review.

  • ДАТИРОВКА ASTER TIR архив 2000-2003 устарел на 22-25 лет. Surface mineralogy могла существенно измениться, особенно в зонах galamsey (снос верхнего слоя, изменение drainage). QI/CI индексы отражают состояние на начало 2000-х, не текущее. Использовать только как региональный структурный контекст.
  • МЕТОДОЛОГИЯ Galamsey маска: Hansen-AND-S1 (strict) vs raw S1. Использована strict маска (пересечение Hansen GFC и S1 изменений) — более консервативная и юридически защитимая оценка. Raw S1 маска даёт верхнюю границу (~2-3× выше). Bodukwan и FGM — highest galamsey в обоих методологиях.
  • ДАННЫЕ Akim Apapam Landsat SWIR отсутствует (tile boundary bug). При загрузке SWIR-данных akim_apapam попал на стык двух Landsat tile'ов; fallback на ASTER SWIR обеспечивает частичное покрытие. Это занижает satellite score akim_apapam. Требуется повторный download с expanded bbox.
  • КООРДИНАТЫ Akim Apapam и Obomeng — NOT_IN_CADASTRE. akim_apapam: координаты взяты из pillars FS (feasibility_pillars_NOT_IN_CADASTRE). obomeng: approximate centroid около Konongo. Вся спутниковая аналитика по этим концессиям опирается на предположение о корректности координат — требуется верификация через Ghana Minerals Commission.
  • EMIT EMIT hyperspectral: NASA CMR подтвердил coverage 7/7 концессий, данные не скачаны. Загрузка требует Earthdata netrc (бесплатный аккаунт, ~5 мин регистрация). После загрузки EMIT mineral maps добавят 8-й независимый сенсор к scoring.
  • ГЕОФИЗИКА WGM2012 заменён на EGM2008 (BGI registration required) — gravity grid 27 km/pixel. Разрешение EMAG2v3 ~0.84 km/pixel (TMI) и ~27 km/pixel (gravity) — оба являются региональным контекстом, не концессионными данными. Residual Bouguer для малых концессий (<3 gravity pixels) = 0 или null. Использовать только как background context.
  • ФОРМУЛА Confidence_score = 50% data_completeness + 50% documentary_completeness. Текущее взвешивание 50/50 — настраиваемо под investor preference. Для conservative финансового DD: 30/70 (больше веса документам). Для exploration stage: 70/30 (больше веса сенсорам).
  • RESERVE TYPES Hard-rock vs alluvial: принципиально разные ресурсы. Oworam/Amenam/Akim Apapam reserves — alluvial only (dredge/sluice). Hard-rock потенциал extrapolated по региональной аналогии (Amenam: broken figures). Akim Apapam rock chips 8.1 г/т — hard-rock signal, но объёмная оценка отсутствует. Инвестиционные решения по hard-rock и alluvial — принципиально разные risk/return profiles.
  • TIER RULES Правила определения evidence_tier. A = ≥10 assays OR (≥1 FS ≥50pp AND reserve_oz known); B = ≥1 assay/channel sample; C = work programme only (soil + RC planned не выполнено); title_only = только лицензия, нет геологических данных; empty = нет документации в архиве.
